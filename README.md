# Elite Fitness Gym Website

## Project Overview

This project is a fitness website designed to provide users with information about gym services and allow enquiries.

## Organisation

Elite Fitness Gym is a fitness centre focused on helping individuals achieve their health goals.

## Website Goals

* Increase membership
* Provide information
* Allow user enquiries

## Features

* Navigation menu
* Multiple pages
* Responsive design

## Pages

* Home
* About
* Services
* Enquiry
* Contact

## Technologies Used
